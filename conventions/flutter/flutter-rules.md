# Flutter Rules

**Ultima revision:** 2026-07-29

## Alcance

Aplica a arquitectura, state management, routing, servicios genericos, consumo
API, modelos, widgets shared, theming, formularios, errores, storage, auth,
notificaciones, testing y performance.

## Reglas

- Shared no se toca sin analisis de impacto y aprobacion explicita.
- Debe existir catalogo oficial de servicios genericos por caso de uso.
- Debe existir catalogo de prohibiciones explicitas.
- Si falta una regla, se propone y se espera aprobacion antes de ejecutarla.
