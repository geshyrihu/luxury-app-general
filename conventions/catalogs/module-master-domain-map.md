# Module Master Domain Map

**Ultima revision:** 2026-07-29

## Objetivo

Mapear dominios maestros backend con sus equivalentes frontend y futuros stacks.

## Ejemplos

- `AdminLuxuryApp` <-> `admin.luxuryapp`
- `ContabilidadLuxuryApp` <-> dominio frontend equivalente cuando aplique
- `CobranzaLuxuryApp` <-> `cobranza.luxuryapp`

## Regla

Toda creacion, documentacion, auditoria o remediacion debe validar primero el
dominio maestro correcto.
