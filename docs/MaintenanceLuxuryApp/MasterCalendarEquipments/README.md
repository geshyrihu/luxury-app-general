# Modulo: CalendarioMaestroEquipo (Equipos del Calendario Maestro)

> **Area funcional:** Mantenimiento / Catalogos
> **Owner tecnico:** `@equipo-mantenimiento`
> **Ultima actualizacion:** `2026-06-25`

---

Define las entradas de equipos/activos que aparecen en el Calendario Maestro. Asocia nombres de equipo con su clasificacion. Requiere rol SuperUsuario.

| Metodo | Ruta | Descripcion |
|--------|------|-------------|
| `GET` | `api/CalendarioMaestroEquipo/{id}` | Entrada por ID |
| `GET` | `api/CalendarioMaestroEquipo` | Lista completa |
| `POST` | `api/CalendarioMaestroEquipo` | Crear |
| `PUT` | `api/CalendarioMaestroEquipo/{id}` | Actualizar |
| `DELETE` | `api/CalendarioMaestroEquipo/{id}` | Eliminar |
