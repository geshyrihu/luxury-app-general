# CustomerProvider (Cliente-Proveedor)

> **Modulo padre:** Reclutamiento
> **Ultima actualizacion:** `2026-06-25`

Relacion entre clientes (condominios) y proveedores con categoria.

| Metodo | Ruta | Descripcion |
|--------|------|-------------|
| `GET` | `api/CustomerProvider/{customerId}` | Proveedores por cliente |
| `GET` | `api/CustomerProvider/GetById/{id}` | Relacion por ID |
| `POST` | `api/CustomerProvider` | Crear |
| `PUT` | `api/CustomerProvider/{id}` | Actualizar |
| `DELETE` | `api/CustomerProvider/{id}` | Eliminar |
