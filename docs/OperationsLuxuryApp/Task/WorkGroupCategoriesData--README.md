# WorkGroupCategories (Categorias de Grupos)

> **Modulo padre:** Tasks
> **Ultima actualizacion:** `2026-06-25`

Categorias para clasificar grupos de trabajo.

| Metodo | Ruta | Descripcion |
|--------|------|-------------|
| `GET` | `api/task-group-categories/{id}` | Por ID |
| `GET` | `api/task-group-categories` | Listar |
| `POST` | `api/task-group-categories` | Crear |
| `PUT` | `api/task-group-categories/{id}` | Actualizar |
| `DELETE` | `api/task-group-categories/{id}` | Eliminar |
