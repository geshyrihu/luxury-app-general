# TaskWorkPlan (Plan de Trabajo Semanal)

> **Modulo padre:** Tasks
> **Ultima actualizacion:** `2026-06-25`

Plan de trabajo semanal con pendientes y reporte.

| Metodo | Ruta | Descripcion |
|--------|------|-------------|
| `GET` | `api/task-work-plan/Pending/{customerId}` | Pendientes |
| `GET` | `api/task-work-plan/preview/{customerId}/{year}/{weekNumber}` | Vista previa |
| `GET` | `api/task-work-plan/Create/{applicationUserId}/{customerId}/{year}/{weekNumber}` | Crear plan semanal |
