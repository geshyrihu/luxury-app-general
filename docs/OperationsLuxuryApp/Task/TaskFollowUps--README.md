# TaskFollowUp (Seguimiento de Tickets)

> **Modulo padre:** Tasks
> **Ultima actualizacion:** `2026-06-25`

Mensajes de seguimiento en tickets/tareas.

| Metodo | Ruta | Descripcion |
|--------|------|-------------|
| `GET` | `api/task-follow-up/List/{TaskGroupId}` | Seguimientos de un task |
| `POST` | `api/task-follow-up` | Crear mensaje |
| `DELETE` | `api/task-follow-up/{id}` | Eliminar (solo SuperUsuario) |
