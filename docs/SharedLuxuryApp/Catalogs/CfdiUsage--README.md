# UsoCfdi (Usos de CFDI SAT)

> **Area:** Sistema / Catalogos
> **Ultima actualizacion:** `2026-06-25`

Catalogo SAT de usos de CFDI (destino fiscal de facturas). Solo `SuperUsuario`.

| Metodo | Ruta | Descripcion |
|--------|------|-------------|
| `GET` | `api/cfdi-use` | Listar |
| `GET` | `api/cfdi-use/{id}` | Por ID |
| `POST` | `api/cfdi-use` | Crear |
| `PUT` | `api/cfdi-use/{id}` | Actualizar |
| `DELETE` | `api/cfdi-use/{id}` | Eliminar |

**Reglas:** Ordenado por `Descripcion`. Entidad: `UsoCFDI`.
