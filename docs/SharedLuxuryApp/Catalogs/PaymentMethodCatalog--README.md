# MetodoPago (Metodos de Pago SAT)

> **Area:** Sistema / Catalogos
> **Ultima actualizacion:** `2026-06-25`

Catalogo SAT de metodos de pago (PUE, PPD). Solo `SuperUsuario`.

| Metodo | Ruta | Descripcion |
|--------|------|-------------|
| `GET` | `api/MetodoPago` | Listar |
| `GET` | `api/MetodoPago/{id}` | Por ID |
| `POST` | `api/MetodoPago` | Crear |
| `PUT` | `api/MetodoPago/{id}` | Actualizar |
| `DELETE` | `api/MetodoPago/{id}` | Eliminar |

**Reglas:** Ordenado por `Descripcion`. Entidad: `MetodoDePago`.
