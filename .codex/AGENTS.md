# Codex Instructions - LuxuryApp

## Regla de oro

Las reglas **OBLIGATORIAS** del proyecto estan en `conventions/CONVENTIONS.md` y
`conventions/*`. Este archivo no define reglas de codigo del proyecto; solo
comportamiento especifico de Codex.

## Orden obligatorio antes de trabajar

1. leer `conventions/CONVENTIONS.md`
2. leer los documentos de `conventions/*` que apliquen al tipo de tarea
3. usar despues skills o conocimiento generico solo si no contradicen el sistema rector

## Comportamiento Codex

- referenciar `conventions/CONVENTIONS.md` para backend, frontend, flutter, auditoria,
  documentacion, UI, styles, naming y gobernanza
- no duplicar reglas del proyecto en este archivo
- si una skill o sugerencia generica contradice el repo, gana el sistema rector
- tratar el `conventions-viewer` como capa subordinada, no como fuente de verdad
